# Reproducibility artifact — OEIS A181280 closed form

Exact-arithmetic verification of the paper *A proof of the conjectured closed form for OEIS
A181280*. Every object is rebuilt from the definitions; no external data file is required
(the one `.json` below is generated by a script in this directory, then consumed by another).

## Dependencies

Python 3.8+ and `sympy` (the only non-standard-library dependency). Everything else is the
standard library (`fractions`, `itertools`, `collections`, `json`). See `../requirements.txt`.

```bash
python -m pip install -r ../requirements.txt   # installs sympy
```

## Reproduce order

Two scripts have an ordering dependency; otherwise the files are independent. The
load-bearing chain (matches the paper's Section "Computational verification"):

```bash
# 1. the count and the OEIS match (the 1242-state transfer matrix), n<=12
python transfer.py

# 2. the rigorous minimal-order certificate: a-priori Krylov bound (order <= 16); det H_11 != 0
#    (order >= 11); p DERIVED from the shifted 11x11 Hankel solve; residual p(E)a = 0 for 26
#    consecutive indices >= the 16 the propagation argument needs (order <= 11) => order exactly 11
python proof_matrix.py

# 3. an INDEPENDENT recount by a different machine (8-state Walsh-Hadamard/Fourier route);
#    writes a_terms_fourier.json   <-- run this BEFORE step 4
python machine_fourier_coupled.py

# 4. independent Berlekamp-Massey recurrence + closed-form solve; the symbolic difference
#    against Kauers-Koutschan Conjecture 20 is exactly 0.   (reads a_terms_fourier.json)
python derive_closed_form.py

# 5. a(n) == Conjecture 20 for n = 4..60 (far beyond the 11 the proof needs)
python recurrence.py

# optional, slow: literal brute force over all 16^n matrices, n<=6/7 (independent of the automaton)
python brute.py          # iterates over 16^n column choices
python brute_indep.py    # second, differently written brute force (increasing row-tuples)
```

## Claim → driver map (paper Section "Computational verification")

| Paper item | Script | Expected output |
|---|---|---|
| 1242 states; a(n) vs OEIS, n<=12 | `transfer.py` | all `[OK]` through n=12 |
| literal brute force: both agree a(4),a(5),a(6); row-tuple version also a(7) | `brute.py` (n<=6), `brute_indep.py` (n<=7) | 58, 1629, 28924 (both); 507052 (brute_indep) |
| Krylov dim 16; det H_11 != 0; p from shifted 11x11 solve; 26 >= 16 consecutive zero residuals | `proof_matrix.py` | `Krylov dim ... = 16`; `det H_11 = ... NONSINGULAR`; factored p; `26 ... consecutive ... YES` |
| char poly two ways (shifted-Hankel solve + Berlekamp-Massey) | `proof_matrix.py`, `derive_closed_form.py` | `(x-16)(x-8)^2(x+8)(x-4)^3(x+4)^2(x-2)^2` |
| exponential-basis coeffs; symbolic C(n)-closed = 0 | `derive_closed_form.py` | `closed_form - C20 simplified to: 0` |
| a(n) = C20(n), n=4..60 | `recurrence.py` | `ALL n=4..60 match: True` |
| independent Fourier recount, n<=12 | `machine_fourier_coupled.py` | `ALL MATCH` |

`seeds.txt` lists the exact values a(0..14) used as the proof's seed window.

## Files

- `transfer.py` — the exact 1242-state column-by-column transfer matrix; `a(n)=u T^n e0`.
- `brute.py` — literal brute force over all 16^n matrices (column enumeration), n<=6.
- `brute_indep.py` — independent brute force (increasing row-tuples; popcount Gram), n<=7.
- `proof_matrix.py` — the rigorous minimal-order certificate: a-priori Krylov bound (order <= 16),
  `det H_11 != 0` (order >= 11), `p` derived by the shifted 11x11 Hankel solve, and the
  residual-propagation check (26 >= 16 consecutive zeros). **The proof's load-bearing script.**
- `derive_closed_form.py` — independent Berlekamp-Massey recurrence recovery + exact closed-form
  solve + symbolic comparison to Conjecture 20 (reads `a_terms_fourier.json`).
- `machine_fourier_coupled.py` — a structurally different (8-state Fourier-diagonalized) recount,
  the independent cross-derivation; writes `a_terms_fourier.json`.
- `recurrence.py` — exact terms + `a(n)==C20(n)` for n=4..60.
- `seeds.txt` — exact a(0..14).

On arXiv this directory ships as the standard ancillary directory `anc/`.
